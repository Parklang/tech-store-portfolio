# TechStore - Premium E-commerce Experience

A modern, highly-polished e-commerce front-end application built to showcase premium tech gadgets. This project demonstrates strong foundational layout techniques, state management, and an eye for high-end UI design without relying on any CSS framework.

## Features
- **Glassmorphism & Dark Mode Aesthetic:** A custom, fully-fluid design system using Vanilla CSS.
- **Interactive Product Modal:** Immersive product detail viewing utilizing React state properties and CSS overlay transitions.
- **Dynamic Shopping Cart:** Sliding sidebar cart with real-time state aggregation and calculations.
- **Responsive Architecture:** Optimized for Desktop, Tablet, and Mobile devices using CSS Grid and Flexbox.
- **Micro-Animations:** Butter-smooth hover effects, transform scaling, and beautiful entry transitions.

## Tech Stack
- **Framework:** React 18 (via Vite)
- **Styling:** Vanilla CSS & CSS Variables
- **Icons:** Lucide React

## Getting Started

1. Clone the project or download the folder.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Access the store at `http://localhost:5173/`
